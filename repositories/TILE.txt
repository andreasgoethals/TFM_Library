# TILE: Table-Interfaced LLM Embeddings

[![License](https://img.shields.io/badge/License-BSD_3--Clause-blue.svg)](https://opensource.org/licenses/BSD-3-Clause)
[![Hugging Face](https://img.shields.io/badge/Hugging%20Face-Datasets-yellow)](https://huggingface.co/datasets/inria-soda/TILE-benchmark)
[![arXiv](https://img.shields.io/badge/arXiv-2610.17065-blue.svg)](https://arxiv.org/pdf/2610.17065)

Paper: [TILE: Bridging LLMs and Table Foundation Models for Tabular Learning
with Strings](https://arxiv.org/pdf/2610.17065)

TILE brings the string columns of a table to a tabular learner, such as a
table foundation model like TabPFN, through the embeddings of a truncated
LLM. This repository runs TILE on a table: it downloads and truncates the
LLMs, extracts the cell embeddings, and evaluates TILE with a tabular learner.

## How it works

<img src="figures/tile_schema.svg" width="100%" alt="TILE pipeline: row serialization, extraction from the intermediate layers of an LLM, columnar pooling and PCA, and in-context prediction by a table foundation model">

1. **Serialization.** Each row becomes one text, one sentence per cell:
   `The <column> is <value>. The <column> is <value>. ...`. Every column except
   the target is included, numbers and dates too.
2. **Cell embeddings.** The text goes through the first layers of an LLM: by
   default, the first 14 layers of Llama-3.1-8B. The hidden states of the
   tokens of each cell are mean-pooled. This gives one embedding per cell,
   which has seen the cells before it in the row.
3. **Reduction.** The embeddings of each string column are standardized and
   reduced by their own PCA, to 30 components. The number of components is
   then rescaled so that the whole input of the learner falls inside its
   *feature window*: the range of input widths the learner handles best.
4. **Tabular learner.** The learner receives the reduced embeddings, along
   with:
   - the numerical and date columns, through skrub's `TableVectorizer`;
   - a target encoding of the string columns, computed out of fold;
   - for the learners that take categories, the string columns with fewer than
     50 distinct values.

## Installation

```bash
pip install -e ".[llm,tabpfn,tabicl]"
```

The `llm` extra installs what the extraction of the embeddings needs. Each
learner has its own extra, pinned to the version used in the paper. Some
learners conflict with each other, so they need a separate environment.
The foundation models download their checkpoints on first use. The TabPFN
checkpoints require you to accept their license, for example through the
`TABPFN_TOKEN` environment variable (see the TabPFN documentation).

## 1. Download and truncate the LLMs

The Llama models are gated: accept their license on the Hugging Face hub, then
log in with `hf auth login`.

```bash
python scripts/download_llms.py                   # Llama-3.1-8B
python scripts/download_llms.py --llms all        # the 7 LLMs of the paper
```

Each LLM is cut at one of the layers whose cell embeddings predicted best in
the layer probing of the paper, and saved to `models/<llm>`. The scores of the
top layers are close: for some LLMs, the layer kept is not the very best of
the final probing runs, but one of its top three.

| LLM | Name | Layers kept |
|---|---|---|
| Llama-3.1-8B (default) | `llama-3.1-8b` | 14 of 32 |
| Llama-3.1-70B | `llama-3.1-70b` | 32 of 80 |
| Llama-3.2-1B | `llama-3.2-1b` | 10 of 16 |
| Llama-3.2-3B | `llama-3.2-3b` | 11 of 28 |
| Qwen3-0.6B-Base | `qwen3-0.6b-base` | 16 of 28 |
| Qwen3-4B-Base | `qwen3-4b-base` | 20 of 36 |
| Qwen3-8B-Base | `qwen3-8b-base` | 19 of 36 |

Only the weights of the kept layers are loaded. The loading report lists the
other layers as `UNEXPECTED`; this is expected. To run TILE with one of these
LLMs, see [Using another LLM](#using-another-llm); to add an LLM of your own,
see [Adding an LLM](#adding-an-llm).

## 2. Extract the embeddings

A table is a `.parquet` or `.csv` file:

```bash
python scripts/extract_embeddings.py --table data/my_table.parquet --target price
```

A table can also be the folder of a table of the TILE or STRABLE benchmark:
its `data.parquet`, with a `config.json` that gives the target and the task.
Then `--target` (and `--task` below) can be left out, and the table is named
after its folder.

The embeddings are saved to `embeddings/<llm>/my_table.npy`. This is a float16
array of shape (columns, rows, hidden size). Next to it, a `.json` file holds
the columns and the extraction statistics: time, peak GPU memory and GPU.

Rows are batched by a budget of 65,536 tokens (`--max_tokens`). Lower it if
the GPU runs out of memory. Truncated to 32 layers, Llama-3.1-70B needs about
56 GB of GPU memory for its weights. It is spread over the visible GPUs.

## 3. Evaluate TILE

```bash
python scripts/evaluate.py --table data/my_table.parquet --target price \
    --task regression --learner tabpfn-2.5
```

There are two protocols (`--protocol`):

- `holdout` (default), the protocol of the paper's benchmark. The learner is
  trained on `--num_train` rows drawn at random (default 1024) and tested on
  up to 1024 other rows, for 5 seeds. The draw is stratified for a
  classification. A table with no more rows than `--num_train` is skipped.
- `strable`, the protocol of the STRABLE benchmark: a 3-fold cross-validation
  over every row, stratified for a classification.

The scores are R² and RMSE for a regression, and ROC AUC and accuracy for a
classification. For more than two classes, the ROC AUC is one-vs-rest,
macro-averaged.

Each split is saved to
`results/<protocol>/my_table/<llm>_<learner>_<split>.csv`, and a split already
done is skipped. Besides the scores, a result holds:

- the width of the learner's input;
- the fit and prediction times;
- the share of the extraction time that falls on the rows used;
- the peak GPU memory of the learner.

### Using another LLM

TILE runs with Llama-3.1-8B by default. To run it with another LLM, download
it, then pass its name (see the table of step 1) with `--llm`, to both the
extraction and the evaluation:

```bash
python scripts/download_llms.py --llms qwen3-8b-base
python scripts/extract_embeddings.py --table data/my_table.parquet --target price \
    --llm qwen3-8b-base
python scripts/evaluate.py --table data/my_table.parquet --target price \
    --task regression --learner tabpfn-2.5 --llm qwen3-8b-base
```

The embeddings of each LLM are kept apart, in `embeddings/<llm>/`, and the
results are named after it, so the LLMs can be compared on the same tables. In
the Python API, load the embeddings of that LLM:
`Embeddings.load("embeddings/qwen3-8b-base/my_table.npy")`. An LLM added with
`scripts/add_llm.py` is used the same way, under the name it was given.

### Learners and their feature windows

The window of a learner was selected on the 27 tables of the paper's probing
(see [Adding a tabular learner](#adding-a-tabular-learner)). The learners
without a window keep 30 components per string column, whatever the width of
the table.

| Learner | Name | Feature window | Categories |
|---|---|---|---|
| TabPFN-2.5 | `tabpfn-2.5` | 200 to 400 | ✓ |
| TabPFN-3 | `tabpfn-3` | 150 to 400 | ✓ |
| TabPFN-3.5 | `tabpfn-3.5` | 200 to 800 | ✓ |
| TabICLv2 | `tabicl` | 200 to 800 | ✓ |
| EXAONE-Tabular | `exaone` | 150 to 400 | ✓ |
| Causilo | `causilo` | 200 to 800 | ✓ |
| KumoTabular (small, medium, large) | `kumo-small`, `kumo-medium`, `kumo-large` | 200 to 600 | ✓ |
| RealMLP | `realmlp` | none | |
| XGBoost | `xgboost` | none | |
| CatBoost | `catboost` | none | |
| Ridge | `ridge` | none | |

XGBoost is tuned: the best of its defaults and 99 random configurations, by a
5-fold cross-validation repeated 5 times. RealMLP runs its own search. The
other learners keep their defaults.

## Reproducing the TILE benchmark results

The paper's benchmark gathers 100 tables with strings, from CARTE,
TextTabBench and WikiDBs, released as the
[TILE benchmark](https://huggingface.co/datasets/inria-soda/TILE-benchmark).

**1. Download the tables** (206 MB). Each table is a folder holding
`data.parquet` and a `config.json` with its target and task:

```bash
hf download inria-soda/TILE-benchmark --repo-type dataset --local-dir data/tile
```

**2. Extract the embeddings and evaluate TILE** on every table, with the
holdout protocol, on 1,024, 10,000 and 50,000 training rows as in the paper.
The tables too small for a training size are skipped:

```bash
LLM=llama-3.1-8b
LEARNER=tabpfn-2.5
for dir in data/tile/*/; do
    python scripts/extract_embeddings.py --table "$dir" --llm "$LLM"
    for n in 1024 10000 50000; do
        python scripts/evaluate.py --table "$dir" --llm "$LLM" --learner "$LEARNER" \
            --num_train $n
    done
done
```

The embeddings are extracted once per table and LLM, and reused by every
learner. A split already evaluated is skipped, so the loop can be run again
after an interruption. Each learner runs from its own environment (see
Installation). The results of a table are saved to `results/holdout/<table>/`,
one file per seed and training size. To gather them:

```python
import pandas as pd
from glob import glob

results = pd.concat(map(pd.read_csv, glob("results/holdout/*/*.csv")))
print(results.groupby(["llm", "learner", "n_train"])[["r2", "roc_auc"]].mean())
```

## Reproducing the STRABLE results

The paper evaluates TILE on the 108 tables of the
[STRABLE benchmark](https://huggingface.co/datasets/inria-soda/STRABLE-benchmark),
with the STRABLE protocol.

**1. Download the tables** (210 MB), in the same layout as the TILE benchmark:

```bash
hf download inria-soda/STRABLE-benchmark --repo-type dataset \
    --include "*/data.parquet" "*/config.json" --local-dir data/strable
```

**2. Extract the embeddings and evaluate TILE** on every table:

```bash
LLM=llama-3.1-8b
LEARNER=tabpfn-2.5
for dir in data/strable/*/; do
    python scripts/extract_embeddings.py --table "$dir" --llm "$LLM"
    python scripts/evaluate.py --table "$dir" --llm "$LLM" --learner "$LEARNER" \
        --protocol strable
done
```

The results of a table are saved to `results/strable/<table>/`, one file per
fold.

**Results.** Raw scores of the paper (×100), by tabular learner:

- **Classification:** the ROC AUC, averaged over the 32 classification tables.
- **Regression:** the R² clipped at 0, averaged over the 76 regression tables.

Each table is scored by its average over the 3 folds.

- **TF-IDF:** the TF-IDF baseline of STRABLE with the same learner.
- **Best other encoder:** the best of the other string encoders of the
  [STRABLE leaderboard](https://huggingface.co/spaces/inria-soda/strable-leaderboard)
  with that learner, chosen separately for each task.

| Learner | TILE (Llama-3.1-8B) | TILE (Llama-3.1-70B) | TF-IDF | Best other encoder |
|---|---|---|---|---|
| **Classification ROC AUC** | | | | |
| KumoTabular-L | 87.64 | **87.96** | 87.10 | 87.05 (Qwen3-Embedding-8B, first 30 dims) |
| Causilo | 87.19 | **87.63** | 86.36 | 86.34 (Qwen3-Embedding-8B, first 30 dims) |
| TabPFN-3.5 | 87.27 | **87.66** | 86.75 | 86.56 (Qwen3-Embedding-8B, first 30 dims) |

| TabICLv2 | 86.62 | **87.05** | 85.38 | 85.06 (Qwen3-Embedding-8B, first 30 dims) |
| TabPFN-3 | 86.18 | **86.75** | 85.19 | 84.75 (Qwen3-Embedding-8B, first 30 dims) |
| **Regression R²** | | | | |
| KumoTabular-L | 74.68 | **75.45** | 72.73 | 73.02 (Llama-3.1-8B, first 30 dims) |
| Causilo | 73.41 | **74.23** | 70.66 | 71.52 (Qwen3-Embedding-8B, first 30 dims) |

The paper's runs used one A100 or A40 GPU and 150 GB of RAM per table. The
tables have from 550 to 75,000 rows, and each fold trains on two thirds of
them. A learner that runs out of GPU memory through
fragmentation can be run with `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True`.

## Adding an LLM

`scripts/add_llm.py` makes any decoder LLM of the Hugging Face hub an LLM of
TILE, with the selection of the paper. Every layer is probed on the 27
probing tables of the TILE benchmark, downloaded to `data/tile` (see above):

- only the string columns are serialized, and the cell embeddings of a row,
  side by side and without any reduction, feed a Ridge;
- the Ridge is trained on 1,024 rows and tested on up to 1,024 others, for 5
  seeds;
- the score of a table is its R², clipped at 0, or its ROC AUC, averaged over
  the seeds.

The LLM is then cut at the layer of the best mean score over the tables:

```bash
python scripts/add_llm.py --name mistral-7b --repo_id mistralai/Mistral-7B-v0.3
python scripts/extract_embeddings.py --table data/tile/carte_wina_pl --llm mistral-7b
```

The truncated LLM is saved to `models/mistral-7b`, with the mean score of every
layer in `probing.json`. `--llm mistral-7b` then runs TILE with it. The
script prints the line that adds it to `LLMS` in `tile/llms.py`, for
`download_llms.py`.

The score of each table is saved to `results/probing/<name>/`, and a table
already probed is skipped. The full LLM is loaded, spread over the visible
GPUs, and the hidden states of every layer are held on the GPU for a batch of
rows: lower `--max_tokens` (default 8,192) if it runs out of memory. The cell
embeddings of every layer of a table are held at once: about 21 GB for
Llama-3.1-8B on the largest table, which `--tmp_dir` puts on disk instead of
in memory. `--step 2` probes every other layer, to halve that.

## Adding a table foundation model

A new table foundation model, takes two steps.

**1. Add it to `tile/learners.py`**, without a window: an entry in `LEARNERS`,
such as `"my-tfm": Learner(native_categories=True)`, and a branch in
`make_learner` that builds it. Its input is an array whose first `n_base`
columns are numbers; with `native_categories`, the columns after them are the
string columns of fewer than 50 distinct values, as strings, missing values as
`"nan"`.

**2. Find its feature window:**

```bash
python scripts/feature_window.py --learner my-tfm
```

TILE runs on the 27 probing tables with the whole input of the learner pinned
to each of 50, 100, 150, 200, 300, 400, 600, 800 and 1,200 features, for 5
seeds of 1,024 training rows. The embeddings of Llama-3.1-8B (`--llm`) that are
missing are extracted first.

For each table, the error at a budget (1 - score) is divided by the error at
the best budget. The window is the run of budgets around the best one whose
mean ratio over the tables, minus one standard error, is within 1% of the best.

The script prints the window and the line to put in `LEARNERS`, such as
`"my-tfm": Learner((200, 600), True)`. If the window reaches the smallest or
the largest budget, its bound may lie beyond: run more with `--budgets`. The
score of each split is saved to `results/feature_window/<llm>/<learner>/`, and
a split already done is skipped.

## Python API

```python
from tile import TILE, Embeddings
from tile.data import load_table

table = load_table("data/my_table.parquet")
embeddings = Embeddings.load("embeddings/llama-3.1-8b/my_table.npy")
X, y = table.drop(columns="price"), table["price"]
train, test = range(0, 1000), range(1000, 1500)

model = TILE(learner="tabpfn-2.5", task="regression")
model.fit(X.iloc[train], y.iloc[train], embeddings.take(train))
prediction = model.predict(X.iloc[test], embeddings.take(test))
```

`Embeddings.take` restricts the embeddings to some rows of the table, given
by position. The embeddings of each column are only read from disk when they
are needed.

## Reproducibility

The LLMs run in bfloat16, and several learners run on GPU: repeated runs, and
runs on other hardware, can differ slightly.

                import torch

                # environments

                    range(args.step, model.config.num_hidden_layers + 1, args.step)

    del model

    layer, mean = best_layer(pd.concat(results))
    print("Mean score (R² clipped at 0, or ROC AUC) of each layer:")
    print(mean.round(4).to_string())

        )
    print(

        f'    "{args.name}": LLM("{args.repo_id}", {layer}),'

"""Loading a table."""

import json
from pathlib import Path

import numpy as np
import pandas as pd


def load_table(path):
    """A table from a parquet or csv file, with the cleaning TILE expects.

    The text columns are of `object` dtype (pandas 3 reads them as `str`),
    their missing values NaN, and the line breaks and tabs within their cells
    spaces.
    """
    path = Path(path)
    table = pd.read_parquet(path) if path.suffix == ".parquet" else pd.read_csv(path)
    for col in table.columns:
        if isinstance(table[col].dtype, pd.StringDtype):
            table[col] = table[col].astype(object)
    table = table.fillna(value=np.nan)
    return table.replace(["\n", "\t", "\r"], [" ", " ", ""], regex=True)


def load_task(path, target=None, task=None):
    """A table, its target, its task and its name.

    `path` is a .parquet or .csv file, named after its stem, or the folder of a
    table of the TILE or STRABLE benchmark, named after the folder: its
    `data.parquet`, with the target and the task read from its `config.json`.
    `target` and `task` ("classification" or "regression") override those of
    the config; a file has none, its task is then None.
    """
    path = Path(path)
    if not path.is_dir():
        if target is None:
            raise ValueError(f"{path} has no config.json: give its target")
        return load_table(path), target, task, path.stem
    with open(path / "config.json") as f:
        config = json.load(f)
    target = target or config["target_name"]
    # "regression", "b-classification" or "m-classification"
    task = task or (
        "regression" if config["task"] == "regression" else "classification"
    )
    return load_table(path / "data.parquet"), target, task, path.name

"""The cell embeddings of a table: each row serialized as one text, read by a
truncated LLM, and the hidden states of each cell mean-pooled."""

import json
import os
import socket
import time
from pathlib import Path

import numpy as np


def serialize(table):
    """Each row as one text, and the characters of each of its cells.

    A row reads "The <column> is <value>. The <column> is <value>. ...", one
    sentence per cell in the order of the table, with the underscores of the
    column names written as spaces, and the missing values and blank strings
    as "NaN".

    Returns:
        texts: The serialized rows.
        spans: (n_rows, n_columns, 2) array, the [start, end) characters of
            each cell sentence in its row.
    """
    names = [str(col).replace("\n", "").replace("_", " ") for col in table.columns]
    values = table.astype(str)
    missing = table.isna() | values.apply(lambda col: col.str.strip() == "")
    values = values.mask(missing, "NaN").to_numpy()

    texts = []
    spans = np.empty((len(values), len(names), 2), dtype=np.int64)
    for i, row in enumerate(values):
        cells, start = [], 0
        for j, (name, value) in enumerate(zip(names, row)):
            cell = f"The {name} is {value}."
            # A value ending in a space ends in "<value>."
            if cell.endswith(" ."):
                cell = cell[:-2] + "."
            spans[i, j] = (start, start + len(cell))
            cells.append(cell)
            start += len(cell) + 1
        texts.append(" ".join(cells))
    return texts, spans


def pool_cells(model, tokenizer, texts, spans, max_tokens=65536, layers=None, out=None):
    """Mean-pools the last hidden state of the model over the tokens of each cell.

    The spans are read off the tokenization of the whole row: a token belongs
    to every cell whose characters it overlaps, so a token that straddles two
    cells is pooled into both. Special and padding tokens cover no character
    and belong to no cell. The rows run from the longest to the shortest, in
    batches of at most `max_tokens` tokens, padding included (a row longer than
    that goes alone).

    With `layers`, the hidden states of these layers are pooled instead, layer
    k the output of the k-th block (0 that of the embeddings), for the layer
    probing: into `out` if given, e.g. a memory map.

    Returns:
        A (n_columns, n_rows, hidden_size) float16 array, or with `layers` a
        (n_layers, n_columns, n_rows, hidden_size) one.
    """
    import torch
    from tqdm import tqdm

    n_rows, n_cols, _ = spans.shape
    # Right padding: under causal attention, no real token then sees the
    # padding, and the positions of the real tokens start at 0 in every row
    tokenizer.padding_side = "right"
    no_bos = len(tokenizer("")["input_ids"]) == 0

    # Token count of each row, in chunks to bound the memory of the encodings
    lengths = np.concatenate(
        [
            [len(ids) for ids in tokenizer(texts[i : i + 10_000])["input_ids"]]
            for i in range(0, n_rows, 10_000)
        ]
    )
    order = np.argsort(-lengths, kind="stable")

    shape = (n_cols, n_rows, model.config.hidden_size)
    if layers is None:
        embeddings = np.empty(shape, np.float16)
        targets = [embeddings]
    else:
        embeddings = np.empty((len(layers), *shape), np.float16) if out is None else out
        targets = list(embeddings)
    start = 0
    with tqdm(total=n_rows, desc="Pooling cells", mininterval=60) as progress:
        while start < n_rows:
            # The first row of the batch is its longest
            batch_size = max(1, max_tokens // lengths[order[start]])
            idx = order[start : start + batch_size]

            inputs = tokenizer(
                [texts[k] for k in idx],
                return_tensors="pt",
                padding=True,
                return_offsets_mapping=True,
            )
            offsets = inputs.pop("offset_mapping")

            with torch.inference_mode():
                outputs = model(
                    **inputs.to(model.device), output_hidden_states=layers is not None
                )
                states = (
                    [outputs.last_hidden_state]
                    if layers is None
                    else [outputs.hidden_states[layer] for layer in layers]
                )

                # (batch, n_cols, seq_len): the token overlaps the cell
                device = states[0].device
                offsets = offsets.to(device)
                cells = torch.as_tensor(spans[idx], device=device)
                tok_start = offsets[:, None, :, 0]
                tok_end = offsets[:, None, :, 1]
                in_cell = (
                    (tok_start < cells[:, :, 1:])
                    & (tok_end > cells[:, :, :1])
                    & (tok_end > tok_start)
                ).float()
                if no_bos:
                    # The sink, the first token of the row
                    in_cell[:, :, 0] = 0
                for target, hidden in zip(targets, states):
                    # The layers of a model spread over GPUs are on different ones
                    weights = in_cell.to(hidden.device)
                    pooled = torch.bmm(weights, hidden.float()) / weights.sum(
                        -1, keepdim=True
                    )
                    target[:, idx] = pooled.transpose(0, 1).half().cpu().numpy()
            start += len(idx)
            progress.update(len(idx))

    return embeddings


def embed_table(table, model, tokenizer, max_tokens=65536):
    """The cell embeddings of every column of `table`, and how they were made.

    `table` is the table without its target. The extraction time covers the
    serialization, the tokenization and the forward passes; the peak GPU
    memory is the one PyTorch reserved.
    """
    import torch

    on_gpu = torch.cuda.is_available()
    if on_gpu:
        # cuDNN's attention kernel fails on padded batches in some
        # environments (it compiles its kernels with NVRTC): left out
        torch.backends.cuda.enable_cudnn_sdp(False)
        torch.cuda.reset_peak_memory_stats()

    start = time.perf_counter()
    texts, spans = serialize(table)
    embeddings = pool_cells(model, tokenizer, texts, spans, max_tokens)
    stats = {
        "time_s": round(time.perf_counter() - start, 4),
        "max_tokens": max_tokens,
        "node": socket.gethostname(),
    }
    if on_gpu:
        stats["gpu"] = torch.cuda.get_device_name(0)
        stats["peak_gpu_memory_mb"] = round(
            torch.cuda.max_memory_reserved() / 1024**2, 1
        )
    return embeddings, stats


def save(path, embeddings, columns, **info):
    """Saves the embeddings to `path` (.npy), and their columns and `info` next
    to it (.json)."""
    path = Path(path)
    os.makedirs(path.parent, exist_ok=True)

class Embeddings:
    """The cell embeddings of a table, one (n_rows, hidden_size) block per column.

    Read from disk one column at a time, when the column is asked for:
    `embeddings[column]`. `take(rows)` restricts them to some rows of the
    table, as positions.
    """

    def __init__(self, array, columns, info=None, rows=None):
        self.array = array
        self.columns = [str(col) for col in columns]
        self.info = info or {}
        self.rows = rows
        self._index = {col: i for i, col in enumerate(self.columns)}

    @classmethod
    def load(cls, path):
        path = Path(path)
        with open(path.with_suffix(".json")) as f:
            info = json.load(f)
        columns = info.pop("columns")
        return cls(np.load(path, mmap_mode="r"), columns, info)

    def __len__(self):
        return self.array.shape[1] if self.rows is None else len(self.rows)

    def __getitem__(self, column):
        block = self.array[self._index[str(column)]]
        return np.asarray(block if self.rows is None else block[self.rows])

    def take(self, rows):
        rows = np.asarray(rows)
        return Embeddings(
            self.array,
            self.columns,
            self.info,
            rows if self.rows is None else self.rows[rows],
        )

"""The two evaluation protocols of the paper.

`holdout`, the protocol of its benchmark: a training set of `num_train` rows
drawn at random, tested on up to 1024 of the other rows, for 5 seeds.
`strable`, the protocol of the STRABLE benchmark: a 3-fold cross-validation
over every row.
"""

import time

import numpy as np
from scipy.special import softmax
from sklearn.metrics import (
    accuracy_score,
    r2_score,
    roc_auc_score,
    root_mean_squared_error,
)
from sklearn.model_selection import KFold, StratifiedKFold, train_test_split

from tile.model import TILE

PROTOCOLS = ("holdout", "strable")


def splits(y, task, protocol="holdout", num_train=1024):
    """The (name, train rows, test rows) of each split of the protocol."""
    classification = task == "classification"
    if protocol == "holdout":
        if num_train >= len(y):
            raise ValueError(f"{num_train} training rows out of {len(y)}")
        num_test = min(1024, len(y) - num_train)
        return [
            (
                f"n{num_train}_seed{seed}",
                *train_test_split(
                    np.arange(len(y)),
                    train_size=num_train,
                    test_size=num_test,
                    random_state=seed,
                    stratify=y if classification else None,
                ),
            )
            for seed in range(1, 6)
        ]
    folds = (StratifiedKFold if classification else KFold)(
        n_splits=3, shuffle=True, random_state=1234
    )
    return [
        (f"fold{i}", train, test)
        for i, (train, test) in enumerate(folds.split(np.zeros(len(y)), y))
    ]


def scores(y_true, prediction, task):
    """R2 and RMSE of a regression, ROC AUC and accuracy of a classification.

    `y_true` holds the class indices of the columns of the probabilities.
    """
    if task == "regression":
        return {
            "r2": r2_score(y_true, prediction),
            "rmse": root_mean_squared_error(y_true, prediction),
        }
    if prediction.shape[1] == 2:
        auc = roc_auc_score(y_true, prediction[:, 1])
    else:
        # One-vs-rest, macro-averaged, on the softmax of the probabilities:
        # the scores of the paper
        auc = roc_auc_score(
            y_true,
            softmax(prediction, axis=1),
            multi_class="ovr",
            labels=np.arange(prediction.shape[1]),
        )
    return {"roc_auc": auc, "accuracy": accuracy_score(y_true, prediction.argmax(1))}


def _reset_gpu_peak(device):
    if str(device).startswith("cuda"):
        import torch

        torch.cuda.empty_cache()
        torch.cuda.reset_peak_memory_stats()


def _gpu_peak(device):
    if not str(device).startswith("cuda"):
        return {}
    import torch

    return {
        "gpu": torch.cuda.get_device_name(),
        "peak_gpu_memory_mb": round(torch.cuda.max_memory_reserved() / 1024**2, 1),
    }


def evaluate_split(
    X, y, train, test, embeddings, learner, task, device="cuda", window=None
):
    """Fit TILE on the `train` rows, and score it on the `test` rows.

    `X` is the table without its target, `y` the target (class indices for a
    classification), and `embeddings` the cell embeddings of the table.
    `window` replaces the feature window of the learner.
    Besides the scores, the result holds the times of the fit and of the
    predictions, the share of the extraction time of the embeddings that
    falls on the rows used, and the peak GPU memory of the learner.
    """
    tile = TILE(learner, task, device, window)
    _reset_gpu_peak(device)

    start = time.perf_counter()
    tile.fit(X.iloc[train], y[train], embeddings.take(train))
    fit_time = time.perf_counter() - start

    start = time.perf_counter()
    if task == "regression":
        prediction = tile.predict(X.iloc[test], embeddings.take(test))
    else:
        prediction = tile.predict_proba(X.iloc[test], embeddings.take(test))
    predict_time = time.perf_counter() - start

    window = tile.features_.window
    return {
        **scores(y[test], prediction, task),
        "n_train": len(train),
        "n_test": len(test),
        "window": f"{window[0]}-{window[1]}" if window else None,
        "components_per_column": tile.features_.n_components_,
        "n_features": tile.features_.n_base_ + len(tile.features_.categories_),
        "embedding_time": embeddings.info["time_s"]
        * (len(train) + len(test))
        / embeddings.array.shape[1],
        "fit_time": fit_time,
        "predict_time": predict_time,
        **_gpu_peak(device),
    }

"""The input TILE gives a tabular learner: the reduced cell embeddings of the
string columns, next to the features that bypass the LLM."""

from math import ceil, floor

import numpy as np
import pandas as pd
from sklearn.decomposition import PCA
from sklearn.impute import SimpleImputer
from sklearn.model_selection import KFold
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PowerTransformer, StandardScaler

# The PCA components of a string column, before the feature window
COMPONENTS_PER_COLUMN = 30
# A string column with fewer distinct values also reaches the learners that
# take categories as one
CARDINALITY_THRESHOLD = 50
# A string column is worth target-encoding only if enough of its rows share
# their value with another row. Below this fraction the column is nearly all
# singletons: out of fold almost every row falls back to the prior, so the
# encoding is close to a constant.
MIN_REPEAT_RATIO = 0.1


def string_columns(table):
    """The columns of text, in the order of the table: the dates are not."""
    from skrub import to_datetime

    return [
        col
        for col in table.select_dtypes(include="object").columns
        if not pd.api.types.is_datetime64_any_dtype(to_datetime(table[col]))
    ]


def components_per_column(n_columns, window, default=COMPONENTS_PER_COLUMN):
    """The number of PCA components of each of `n_columns` string columns.

    `default` each, unless their total falls outside `window`, a (lower,
    upper) number of features: then the count that brings the total to the
    bound it crosses, rounded towards the inside of the window, at least 1.
    """
    total = default * n_columns
    if n_columns == 0 or window is None or window[0] <= total <= window[1]:
        return default
    if total < window[0]:
        return max(1, ceil(window[0] / n_columns))
    return max(1, floor(window[1] / n_columns))


def _repeat_ratio(values):
    """Fraction of non-missing rows whose value occurs at least twice."""
    present = pd.Series(values).dropna().astype(str)
    if len(present) == 0:
        return 0.0
    counts = present.value_counts()
    return counts[counts >= 2].sum() / len(present)


def _target_stats(codes, y, n_classes):
    """Category -> its encoded row, and the row of a category never seen."""
    if n_classes == 0:
        means = pd.Series(y, index=codes).groupby(level=0).mean()
        return means.to_frame(), np.array([float(np.mean(y))])
    counts = pd.crosstab(codes, y).reindex(columns=range(n_classes), fill_value=0)
    proba = counts.div(counts.sum(axis=1).clip(lower=1), axis=0)
    prior = np.bincount(y, minlength=n_classes) / len(y)
    # The class probabilities sum to one: a binary target needs only P(y = 1)
    if n_classes == 2:
        return proba[[1]], prior[[1]]
    return proba, prior


def _encode(codes, mapping, fallback):
    # `copy=True`: under pandas 3 the array shares the frame's buffer and
    # comes back read-only
    values = mapping.reindex(pd.Index(codes)).to_numpy(dtype=float, copy=True)
    values[np.isnan(values).any(axis=1)] = fallback
    return values


class TargetEncoder:
    """The target encoding of the string columns whose values repeat.

    A category is encoded by P(y = k | category), one column per class (P(y = 1)
    alone for a binary target), or by its mean target for a regression; a
    missing value is a category of its own. The training rows are encoded out
    of fold, so that a row never contributes to its own encoding; the other
    rows by the statistics of every training row. A category never seen gets
    the prior.
    """

    def fit_transform(self, X, y, task, n_splits=5):
        self.columns_ = [
            col for col in X.columns if _repeat_ratio(X[col]) > MIN_REPEAT_RATIO
        ]
        y = np.asarray(y)
        self.n_classes_ = 0
        if task == "classification":
            classes, y = np.unique(y, return_inverse=True)
            self.n_classes_ = len(classes)
        width = self.n_classes_ if self.n_classes_ > 2 else 1

        n = len(X)
        folds = list(
            KFold(min(n_splits, n), shuffle=True, random_state=1234).split(
                np.arange(n)
            )
        )
        encoded = np.empty((n, len(self.columns_) * width))
        self.stats_ = []
        for j, col in enumerate(self.columns_):
            block = slice(j * width, (j + 1) * width)
            codes = X[col].astype(str).to_numpy()
            self.stats_.append(_target_stats(codes, y, self.n_classes_))
            for fit_index, encode_index in folds:
                stats = _target_stats(codes[fit_index], y[fit_index], self.n_classes_)
                encoded[encode_index, block] = _encode(codes[encode_index], *stats)
        return encoded

    def transform(self, X):
        blocks = [
            _encode(X[col].astype(str).to_numpy(), *stats)
            for col, stats in zip(self.columns_, self.stats_)
        ]
        return np.hstack(blocks) if blocks else np.empty((len(X), 0))


class TILEFeatures:
    """The input of the learner, fit on the training rows.

    In this order:
        * the cell embeddings of each string column, standardized and reduced
          by a PCA of their own;
        * the other columns, numbers and dates, through skrub's
          TableVectorizer;
        * the target encoding of the string columns (`TargetEncoder`);
        * with `native_categories`, the string columns of fewer than
          `CARDINALITY_THRESHOLD` distinct values, as strings, for the
          learners that handle categories.

    With a `window`, a (lower, upper) number of features, the PCA components
    are rescaled so that the whole input falls inside it: the features that
    bypass the LLM take their share of the window first. Without one, every
    string column keeps `COMPONENTS_PER_COLUMN` components.
    `power_transform` imputes the numbers and dates and maps them to a normal
    distribution, for a linear learner.
    """

    def __init__(self, window=None, native_categories=False, power_transform=False):
        self.window = window
        self.native_categories = native_categories
        self.power_transform = power_transform

    def fit_transform(self, X, y, embeddings, task):
        from skrub import TableVectorizer

        self.string_columns_ = string_columns(X)
        strings = set(self.string_columns_)
        self.other_columns_ = [col for col in X.columns if col not in strings]

        self.vectorizer_ = TableVectorizer(numeric="passthrough")
        if self.power_transform:
            self.vectorizer_ = make_pipeline(
                self.vectorizer_, SimpleImputer(), PowerTransformer()
            )
        others = X[self.other_columns_]
        numbers = (
            np.array(self.vectorizer_.fit_transform(others))
            if others.shape[1] > 0
            else np.empty((len(X), 0))
        )

        self.target_encoder_ = TargetEncoder()
        encoded = self.target_encoder_.fit_transform(
            X[self.string_columns_], y, task
        )

        self.categories_ = []
        if self.native_categories:
            self.categories_ = [
                col
                for col in self.string_columns_
                if X[col].nunique() < CARDINALITY_THRESHOLD
            ]

        n_bypass = numbers.shape[1] + encoded.shape[1] + len(self.categories_)
        window = self.window
        if window is not None:
            window = tuple(max(0, bound - n_bypass) for bound in window)
        self.n_components_ = components_per_column(len(self.string_columns_), window)

        self.reducers_ = {}
        reduced = []
        for col in self.string_columns_:
            block = embeddings[col]
            reducer = make_pipeline(
                StandardScaler(),
                PCA(int(min(self.n_components_, *block.shape)), random_state=1234),
            )
            reduced.append(reducer.fit_transform(block))
            self.reducers_[col] = reducer

        Z = self._assemble(reduced, numbers, encoded, X)
        # The categories come last
        self.n_base_ = Z.shape[1] - len(self.categories_)
        return Z

    def transform(self, X, embeddings):
        reduced = [
            self.reducers_[col].transform(embeddings[col])
            for col in self.string_columns_
        ]
        others = X[self.other_columns_]
        numbers = (
            np.array(self.vectorizer_.transform(others))
            if others.shape[1] > 0
            else np.empty((len(X), 0))
        )
        encoded = self.target_encoder_.transform(X[self.string_columns_])
        return self._assemble(reduced, numbers, encoded, X)

    def _assemble(self, reduced, numbers, encoded, X):
        Z = np.hstack(reduced + [numbers, encoded])
        if self.categories_:
            # A missing category is the string "nan"
            Z = np.hstack((Z, X[self.categories_].astype(str).to_numpy()))
        return Z

"""Scikit-learn style wrappers of KumoTabular, from NVIDIA's
structured-data-models (https://github.com/NVIDIA/structured-data-models).

The settings follow the TabArena protocol of the package
(`benchmark/tabular/talent/models.py`): 8 estimators for the small and medium
models, 16 for the large one, float16 autocast on GPU, and the mean of the 999
predicted quantiles as the point prediction of a regression.

The columns of strings are its categorical features; it aligns their
categories between the context and the query by value, and maps them to
numbers itself. Its recipe keeps at most 500 columns per estimator.
"""

import numpy as np
import pandas as pd
import torch

N_ESTIMATORS = {"small": 8, "medium": 8, "large": 16}


class _KumoTabular:
    task = None

    def __init__(self, size="large", device="cuda", random_state=1234):
        import sdm

        self.size = size
        self.device = torch.device(device)
        self.random_state = random_state
        self.model = sdm.models.KumoTabular(
            task=self.task, size=size, device=self.device
        )

    def _table(self, X):
        import sdm

        X = pd.DataFrame(X)
        X.columns = [str(col) for col in X.columns]
        if not hasattr(self, "stypes_"):
            self.stypes_ = {
                col: "categorical" if X[col].dtype == object else "numerical"
                for col in X.columns
            }
        return sdm.TableTensor.from_pandas(df=X, stypes=self.stypes_, device=self.device)

    def _fit(self, X, y, y_stype):
        import sdm

        if hasattr(self, "stypes_"):
            del self.stypes_
        x_context = self._table(X)
        y_context = sdm.TableTensor.from_pandas(
            df=pd.DataFrame({"target": np.asarray(y)}),
            stypes={"target": y_stype},
            device=self.device,
        )
        generator = torch.Generator(self.device).manual_seed(self.random_state)
        with torch.amp.autocast(
            self.device.type, torch.float16, enabled=self.device.type == "cuda"
        ):
            self.model.fit(
                x=x_context,
                y=y_context,
                num_estimators=N_ESTIMATORS[self.size],
                generator=generator,
            )
        return self

    def _predict_table(self, X):
        with torch.amp.autocast(
            self.device.type, torch.float16, enabled=self.device.type == "cuda"
        ):
            return self.model.predict(self._table(X))


class KumoTabularClassifier(_KumoTabular):
    task = "classification"

    def fit(self, X, y):
        self.classes_ = np.unique(y)
        return self._fit(X, y, "categorical")

    def predict_proba(self, X):
        from sdm.stype import Stype

        out = self._predict_table(X)
        # One output column per class, named by its value
        columns = list(out.columns[Stype.numerical])
        indices = [columns.index(str(c)) for c in self.classes_]
        return out.numerical[..., indices].float().cpu().numpy()

    def predict(self, X):
        return self.classes_[self.predict_proba(X).argmax(axis=1)]


class KumoTabularRegressor(_KumoTabular):
    task = "regression"

    def fit(self, X, y):
        return self._fit(X, np.asarray(y, dtype=float), "numerical")

    def predict(self, X):
        out = self._predict_table(X)
        return out.numerical.float().mean(dim=-1).cpu().numpy()

class _Frame(TransformerMixin, BaseEstimator):
    """The input as a DataFrame: the first `n_base` columns as floats, the
    others, the categories, as strings.

    `drop_empty` drops the columns missing on every training row, and
    `missing_categories` turns the category "nan" back into a missing value.
    """

    def __init__(self, n_base, drop_empty=False, missing_categories=False):
        self.n_base = n_base
        self.drop_empty = drop_empty
        self.missing_categories = missing_categories

    def fit(self, X, y=None):
        X = self._frame(X)
        self.columns_ = [
            col for col in X.columns if not (self.drop_empty and X[col].isna().all())
        ]
        return self

    def transform(self, X):
        return self._frame(X)[self.columns_]

    def _frame(self, X):
        X = pd.DataFrame(X)
        for col in X.columns[: self.n_base]:
            X[col] = X[col].astype(float)
        if self.missing_categories:
            for col in X.columns[self.n_base :]:
                X[col] = X[col].replace("nan", np.nan)
        return X


class _Ordinal(TransformerMixin, BaseEstimator):
    """The input as floats only, the categories as ordinal codes, the missing
    and unseen ones NaN."""

    def __init__(self, n_base):
        self.n_base = n_base

    def fit(self, X, y=None):
        self.encoder_ = OrdinalEncoder(
            handle_unknown="use_encoded_value",
            unknown_value=np.nan,
            encoded_missing_value=np.nan,
        )
        categories = self._categories(X)
        if categories.shape[1] > 0:
            self.encoder_.fit(categories)
        return self

    def transform(self, X):
        base = np.asarray(X[:, : self.n_base], dtype=float)
        categories = self._categories(X)
        if categories.shape[1] == 0:
            return base
        return np.hstack((base, self.encoder_.transform(categories)))

    def _categories(self, X):
        categories = np.array(X[:, self.n_base :], dtype=object)
        categories[categories == "nan"] = np.nan
        return categories


def make_learner(name, task, device="cuda", n_base=None, params=None):
    """The learner `name` of LEARNERS, for its input from `TILEFeatures`.

    `n_base` is the number of columns of the input before the categories, and
    `params` the hyperparameters of XGBoost. The checkpoints of the foundation
    models are downloaded on first use.
    """
    regression = task == "regression"

    if name.startswith("tabpfn"):
        # TabPFN-3.5 needs tabpfn 9, the others tabpfn 8
        from tabpfn import TabPFNClassifier, TabPFNRegressor
        from tabpfn.constants import ModelVersion

        version = ModelVersion("v" + name.split("-")[1])
        model = TabPFNRegressor if regression else TabPFNClassifier
        return model.create_default_for_version(
            version, device=device, ignore_pretraining_limits=True
        )

    if name == "tabicl":
        from tabicl import TabICLClassifier, TabICLRegressor

        model = TabICLRegressor if regression else TabICLClassifier
        return make_pipeline(
            _Frame(n_base, drop_empty=True), model(device=device, random_state=1234)
        )

    if name == "exaone":
        from exaonetabular import EXAONETabularClassifier, EXAONETabularRegressor

        model = EXAONETabularRegressor if regression else EXAONETabularClassifier
        return make_pipeline(_Ordinal(n_base), model.from_pretrained(device=device))

    if name == "causilo":
        # The columns of strings are its categorical features
        from causilo import CausiloClassifier, CausiloRegressor

        model = CausiloRegressor if regression else CausiloClassifier
        return model(device=device, random_state=1234)

    if name.startswith("kumo"):
        from tile.kumo import KumoTabularClassifier, KumoTabularRegressor

        model = KumoTabularRegressor if regression else KumoTabularClassifier
        return make_pipeline(
            _Frame(n_base, missing_categories=True),
            model(size=name.split("-")[1], device=device, random_state=1234),
        )

    if name == "realmlp":
        # Tuned by its own search
        from pytabkit import RealMLP_HPO_Classifier, RealMLP_HPO_Regressor

        settings = dict(
            device=device,
            n_cv=5,
            n_repeats=1,
            n_hyperopt_steps=50,
            random_state=20122024,
            tmp_folder=tempfile.mkdtemp(prefix="realmlp_"),
        )
        if regression:
            model = RealMLP_HPO_Regressor(**settings)
        else:
            model = RealMLP_HPO_Classifier(val_metric_name="1-auc_ovr", **settings)
        return make_pipeline(SimpleImputer(), model)

    if name == "xgboost":
        from xgboost import XGBClassifier, XGBRegressor

        model = XGBRegressor if regression else XGBClassifier
        return model(**(params or {}))

    if name == "catboost":
        from catboost import CatBoostClassifier, CatBoostRegressor

        # Its fit depends on the number of columns, the empty ones included
        model = CatBoostRegressor if regression else CatBoostClassifier
        return make_pipeline(
            _Frame(n_base, drop_empty=True),
            model(allow_writing_files=False, verbose=False, thread_count=-1),
        )

    if name == "ridge":
        from sklearn.linear_model import RidgeClassifierCV, RidgeCV

        model = RidgeCV if regression else RidgeClassifierCV
        alphas = [1e-4, 1e-3, 1e-2, 1e-1, 1, 10, 100, 1000, 10000]
        return make_pipeline(SimpleImputer(), model(alphas=alphas))

    raise ValueError(f"Unknown learner {name!r}, one of {list(LEARNERS)}")


def tune_xgboost(X, y, task, n_iter=100):
    """The hyperparameters of XGBoost: the best of its defaults and
    `n_iter - 1` random draws of `XGBOOST_SEARCH`, by a 5-fold
    cross-validation repeated 5 times. An empty dict for the defaults."""
    from sklearn.model_selection import (
        RandomizedSearchCV,
        RepeatedKFold,
        RepeatedStratifiedKFold,
        cross_val_score,
    )

    if task == "regression":
        cv = RepeatedKFold(n_splits=5, n_repeats=5, random_state=1234)
        scoring = "r2"
    else:
        cv = RepeatedStratifiedKFold(n_splits=5, n_repeats=5, random_state=1234)
        scoring = "roc_auc" if len(np.unique(y)) == 2 else "roc_auc_ovr"

    default = make_learner("xgboost", task)
    default_score = cross_val_score(
        default, X, y, cv=cv, scoring=scoring, n_jobs=-1
    ).mean()
    search = RandomizedSearchCV(
        default,
        XGBOOST_SEARCH,
        n_iter=n_iter - 1,
        cv=cv,
        scoring=scoring,
        refit=False,
        n_jobs=-1,
        random_state=1234,
    ).fit(X, y)
    return search.best_params_ if search.best_score_ >= default_score else {}


def _chunked(method, model, X):
    if type(model).__name__.startswith("TabPFN"):
        return np.concatenate(
            [method(X[i : i + TABPFN_CHUNK]) for i in range(0, len(X), TABPFN_CHUNK)]
        )
    return method(X)


def predict_proba(model, X):
    """The class probabilities of a fitted learner."""
    if hasattr(model, "predict_proba"):
        return _chunked(model.predict_proba, model, X)
    # RidgeClassifierCV: the sigmoid of its decision function
    scores = expit(model.decision_function(X))
    if scores.ndim == 1:
        return np.column_stack((1 - scores, scores))
    return scores / scores.sum(axis=1, keepdims=True)


def predict(model, X):
    """The predictions of a fitted regressor."""
    return _chunked(model.predict, model, X)

"""The LLMs of TILE: download them, cut them at their layer, and load them."""

from dataclasses import dataclass
from glob import glob


@dataclass(frozen=True)
class LLM:
    repo_id: str
    # The number of transformer blocks kept: the output of the last one is
    # one of the layers whose cell embeddings predicted best in the layer
    # probing of the paper
    layer: int


LLMS = {
    "llama-3.1-8b": LLM("meta-llama/Llama-3.1-8B", 14),
    "llama-3.1-70b": LLM("meta-llama/Llama-3.1-70B", 32),
    "llama-3.2-1b": LLM("meta-llama/Llama-3.2-1B", 10),
    "llama-3.2-3b": LLM("meta-llama/Llama-3.2-3B", 11),
    "qwen3-0.6b-base": LLM("Qwen/Qwen3-0.6B-Base", 16),
    "qwen3-4b-base": LLM("Qwen/Qwen3-4B-Base", 20),
    "qwen3-8b-base": LLM("Qwen/Qwen3-8B-Base", 19),
}
DEFAULT_LLM = "llama-3.1-8b"


def download(repo_id, cache_dir=None):
    """Download an LLM from the Hugging Face hub, and return its local path.

    Only the safetensors weights, the configs and the tokenizer: not the
    original checkpoints that the Llama repositories also hold.
    """
    from huggingface_hub import snapshot_download

    path = snapshot_download(
        repo_id,
        cache_dir=cache_dir,
        allow_patterns=["*.json", "*.safetensors", "*.txt", "tokenizer*"],
        ignore_patterns=["original/*"],
    )
    # Without its tokenizer files, a snapshot still loads a tokenizer: an
    # empty one, which turns every text into the same few tokens, silently
    if not glob(f"{path}/tokenizer*"):
        raise FileNotFoundError(f"No tokenizer files in {path}")
    return path


def truncate(repo_id, layer, save_dir, cache_dir=None):
    """Save the first `layer` blocks of an LLM, with its tokenizer, in bfloat16."""
    import torch
    from transformers import AutoConfig, AutoModel, AutoTokenizer

    path = download(repo_id, cache_dir)
    config = AutoConfig.from_pretrained(path)
    config.num_hidden_layers = layer
    if getattr(config, "layer_types", None) is not None:
        config.layer_types = config.layer_types[: config.num_hidden_layers]
    # The weights of the blocks past the cut are never read
    model = AutoModel.from_pretrained(path, config=config, dtype=torch.bfloat16)
    model.save_pretrained(save_dir)
    AutoTokenizer.from_pretrained(path).save_pretrained(save_dir)


def load(path):
    """A truncated LLM and its tokenizer, on the GPUs if there are any.

    A full LLM loads too, for the layer probing: the output of its last block
    then goes without the final norm, like that of every other block.
    """
    import torch
    from transformers import AutoModel, AutoTokenizer

    model = AutoModel.from_pretrained(path, dtype=torch.bfloat16, device_map="auto")
    # The probing read the raw output of the last block kept: the final norm,
    # which only the output of the last block of the full LLM goes through,
    # is left out
    model.norm = torch.nn.Identity()
    model.config.use_cache = False
    tokenizer = AutoTokenizer.from_pretrained(path)
    if tokenizer.pad_token is None:
        tokenizer.pad_token = tokenizer.eos_token
    return model.eval(), tokenizer

"""TILE on top of a tabular learner."""

import numpy as np

from tile.features import TILEFeatures
from tile.learners import LEARNERS, make_learner, predict, predict_proba, tune_xgboost


class TILE:
    """TILE (Table-Interfaced LLM Embeddings) on top of a tabular learner.

    `fit` and the predictions take the table without its target, and the cell
    embeddings of the same rows (`Embeddings`, restricted to these rows with
    `take`). The string columns reach the learner through their embeddings,
    reduced into the feature window of the learner (see `TILEFeatures`).

    Parameters
    ----------
    learner : str
        One of `LEARNERS`.
    task : str
        "classification" or "regression".
    device : str
        Where the learner runs, "cuda" or "cpu".
    window : tuple, optional
        The feature window, a (lower, upper) number of features, in place of
        that of the learner in `LEARNERS`.
    """

    def __init__(
        self, learner="tabpfn-2.5", task="classification", device="cuda", window=None
    ):
        self.learner = learner
        self.task = task
        self.device = device
        self.window = window

    def fit(self, X, y, embeddings):
        spec = LEARNERS[self.learner]
        y = np.asarray(y)
        if self.task == "classification":
            self.classes_, y = np.unique(y, return_inverse=True)
        else:
            self.y_mean_ = float(np.mean(y))

        self.features_ = TILEFeatures(
            spec.window if self.window is None else self.window,
            spec.native_categories,
            power_transform=self.learner == "ridge",
        )
        Z = self.features_.fit_transform(X, y, embeddings, self.task)
        params = tune_xgboost(Z, y, self.task) if self.learner == "xgboost" else {}
        self.model_ = make_learner(
            self.learner, self.task, self.device, self.features_.n_base_, params
        )
        self.model_.fit(Z, y)
        return self

    def predict_proba(self, X, embeddings):
        """The probability of each class of `classes_`."""
        return predict_proba(self.model_, self.features_.transform(X, embeddings))

    def predict(self, X, embeddings):
        if self.task == "classification":
            return self.classes_[self.predict_proba(X, embeddings).argmax(axis=1)]
        y = predict(self.model_, self.features_.transform(X, embeddings))
        # A learner that fails on a row predicts the mean target there
        y[np.isnan(y)] = self.y_mean_
        return y

"""The two selections of the paper, made on its 27 probing tables: the layer an
LLM is cut at, and the feature window of a tabular learner.

Layer probing. Every layer of the LLM embeds the string columns of a table,
serialized alone. The cell embeddings of a row, side by side and without any
reduction, feed a Ridge, trained on 1,024 rows for the 5 seeds of the holdout
protocol. The LLM is cut at the layer of the best mean score over the tables.

Feature window. TILE runs with the whole input of the learner pinned to each
of `BUDGETS` features in turn (a window of a single width), on the embeddings
of an LLM, on 1,024 training rows for the 5 seeds of the holdout protocol. The
error of a table, 1 - score, is divided by its error at the best budget; the
ratios are averaged over the tables geometrically. The window is the run of
budgets around the best one whose error could be within `TOLERANCE` of it: the
mean ratio, minus one standard error across the tables, on the log scale, is
no more than `TOLERANCE` above the best.

The score of a table is R² clipped at 0, or ROC AUC, averaged over the seeds.
"""

import numpy as np
import pandas as pd

from tile.embeddings import pool_cells, serialize
from tile.evaluation import scores, splits
from tile.features import string_columns
from tile.learners import make_learner, predict, predict_proba

# The widths of the input of the learner of the budget sweep
BUDGETS = (50, 100, 150, 200, 300, 400, 600, 800, 1200)
# At most 1% more error than at the best budget, on average over the tables
TOLERANCE = 0.01
# Floor of the error, so that a near-perfect score does not blow up its ratio
MIN_ERROR = 1e-3


def score(result):
    """R² clipped at 0, or ROC AUC, of the scores of a split."""
    r2 = result.get("r2", np.nan)
    return result["roc_auc"] if pd.isna(r2) else max(r2, 0)


def probe_layers(X, y, task, model, tokenizer, layers, max_tokens=8192, out_dir=None):
    """The score of a Ridge on the cell embeddings of each layer, on each
    split of the holdout protocol (1,024 training rows, 5 seeds).

    `X` is the table without its target, `y` the target (class indices for a
    classification). Only the string columns are serialized, and only the rows
    of the splits embedded. Every layer is held at once, on disk in `out_dir`
    if given (a memory map), else in memory.

    Returns:
        A DataFrame of the layer, the split and its score.
    """
    import tempfile

    X = X[string_columns(X)]
    folds = splits(y, task, "holdout", 1024)
    rows = np.unique(np.concatenate([np.concatenate(fold[1:]) for fold in folds]))
    # The position of a row of the table among the rows embedded
    position = np.empty(len(y), dtype=int)
    position[rows] = np.arange(len(rows))

    texts, spans = serialize(X.iloc[rows])
    shape = (len(layers), X.shape[1], len(rows), model.config.hidden_size)
    with tempfile.TemporaryDirectory(dir=out_dir) as tmp:
        out = None
        if out_dir is not None:
            out = np.lib.format.open_memmap(
                f"{tmp}/layers.npy", mode="w+", dtype=np.float16, shape=shape
            )
        embeddings = pool_cells(
            model, tokenizer, texts, spans, max_tokens, layers=layers, out=out
        )

        results = []
        for layer, cells in zip(layers, embeddings):
            # The cell embeddings of a row, side by side
            Z = np.hstack(list(cells)).astype(np.float32)
            for split, train, test in folds:
                ridge = make_learner("ridge", task).fit(Z[position[train]], y[train])
                Z_test = Z[position[test]]
                prediction = (
                    predict(ridge, Z_test)
                    if task == "regression"
                    else predict_proba(ridge, Z_test)
                )
                result = scores(y[test], prediction, task)
                results.append({"layer": layer, "split": split, "score": score(result)})
    return pd.DataFrame(results)


def best_layer(results):
    """The layer of the best mean score over the tables, and the mean score of
    every layer.

    `results` holds the table, the layer, the split and the score; the layers
    are compared on the tables they all ran on.
    """
    per_table = results.groupby(["table", "layer"])["score"].mean().unstack()
    mean = per_table.dropna().mean()
    return mean.idxmax(), mean


def feature_window(scores):
    """The feature window of a learner, from its budget sweep.

    `scores` is a (table, budget) DataFrame of seed-averaged scores, with the
    budgets as sorted columns, run on every table. Returns the best budget,
    the window, and the mean and standard error, across tables, of the log of
    the error ratio to the best budget.
    """
    log_error = np.log((1 - scores).clip(lower=MIN_ERROR))
    best = log_error.mean().idxmin()
    log_ratio = log_error.sub(log_error[best], axis=0)
    mean, se = log_ratio.mean(), log_ratio.std() / np.sqrt(len(log_ratio))

    # Grow the window from the best budget while the next one stays within the
    # tolerance, so that a noisy budget far from the best cannot widen it
    within = mean - se <= np.log1p(TOLERANCE)
    budgets = list(scores.columns)
    lo = hi = budgets.index(best)
    while lo > 0 and within[budgets[lo - 1]]:
        lo -= 1
    while hi < len(budgets) - 1 and within[budgets[hi + 1]]:
        hi += 1
    return best, (budgets[lo], budgets[hi]), mean, se
